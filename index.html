How this site works

Zigoware is a static blog hosted on GitHub Pages. There's no backend or build step: the browser loads plain files and JavaScript assembles each page.

  • Posts are Markdown Each post is a .md file in /blog-posts/, and its title, date, author and tags live in posts.yml.
  • Pages build in the browser JavaScript reads posts.yml to create the post cards here and on Categories, and the post page renders the Markdown with markdown-it.
  • Local writing helper A small Express server in /local-dev/ serves the files, updates post dates after edits, and copies AI prompts for drafting and registering posts.
